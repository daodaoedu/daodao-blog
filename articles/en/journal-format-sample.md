This page only checks that every Journal article format stays readable across screen widths and in light and dark themes. It is not real content and will be removed before any production release.

## Paragraphs and lists

Body paragraphs should keep a comfortable line height and line length. Here are ordered and unordered lists:

1. Step one: confirm this week's goal
2. Step two: note what you actually did
3. Step three: write down one small step to try next week

- First bullet item
- Second item, written a little longer so you can check that wrapped lines align with the start of the text above
- Third item

### Subheading (H3)

A paragraph under a subheading should keep clear spacing from the heading above it.

## Quote

> Quote blocks show a member's reply or something someone said. Longer quotes should wrap naturally and never run off the screen.

## Code

Inline code looks like this: `weekly-review`. A long code block should scroll sideways inside its own box on narrow screens, without widening the page:

```text
week=2026-W46 member=example-member done="finished the first practice" blocked="not sure who to ask about the next step" next="ask the facilitator one specific question and report back next session"
```

## Wide table

| Field | Example | What it means | Note |
|---|---|---|---|
| What I did this week | Finished the first practice and logged the time | Describe the actual action | No need to compare with others |
| Where I got stuck | Not sure who to ask about the next step | Name the specific difficulty | You can reply privately |
| What I'll try next week | Ask the facilitator one specific question | Write one step you can do | Check back next session |
